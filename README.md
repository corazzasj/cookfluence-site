# Site CookFluence

Première landing page officielle de CookFluence.

## Fichiers
- `index.html` : page principale
- `styles.css` : design responsive
- `script.js` : petit script d'année automatique
- `mentions-legales.html` : page à compléter avant publication
- `confidentialite.html` : politique minimale
- `robots.txt` : directives moteurs de recherche
- `sitemap.xml` : sitemap pour Google

## Important avant publication
1. Remplacer `contact@cookfluence.fr` si cette adresse n'existe pas encore.
2. Vérifier le nom de domaine définitif. Les fichiers utilisent actuellement `https://www.cookfluence.fr/`.
3. Compléter les mentions légales.
4. Ajouter plus tard les vraies captures de l'application si souhaité.
5. Après mise en ligne, déclarer le domaine dans Google Search Console et demander l'indexation de la page d'accueil.
